## 🚩 Featured Projects

### 🧠 NeuroFence — LLM Weight Poisoning & Backdoor Scanner
**AI Security · LLM Security · Model Forensics**

An offline forensic scanning project designed to analyze local LLM checkpoints for suspicious weight patterns and potential backdoor indicators before deployment.

- 🔎 Inspects local `.safetensors` checkpoints and model architecture.
- 🧩 Examines transformer projection tensors and activation patterns.
- 🧪 Investigates potential anomalies for further forensic review.
- 🔒 Designed around offline, isolated model analysis.

**Stack:** Python · PyTorch · Safetensors · Hugging Face ecosystem

*Note: An anomaly alone does not prove a backdoor; findings require validation.*
